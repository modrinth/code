## Канонический набор — `v2/`

**Используйте файлы из [`v2/`](./v2/README.md).** Это актуальная версия:

- **Sora 600** как основной шрифт (лучше гармонирует с геометрией кристалла)
- **3 цветовые схемы**: cyan / ink / slate-neutral
- **Solid + gradient** версии каждого
- **3 размера** лок-апа: lg 480×120, md 320×80, sm 200×50
- **12 иконок**: 3 цвета × {gradient, solid, outline} + 3 favicon (cyan/ink/slate)
- 6 wordmark + 18 lockup + 12 icon = **38 SVG**

Быстрый старт — [v2/README.md](./v2/README.md).

## Геометрия иконки-кристалла (общая для v1 и v2)

Pointy-top гексагон, viewBox `64×64`, центр `(32, 32)`, радиус `28`. 6 фасет сходятся в центре. Цвета — из палитры DESIGN.md §3, без новых токенов.

В v2 иконка доступна в 3 цветовых схемах × 3 стилях:
- **Gradient** — 6 фасет с градиентом, внутреннее свечение, accent-точка
- **Solid** — один цвет с opacity-вариациями фасет для глубины
- **Outline** — только контур гекса + внутренние линии

Плюс 3 favicon варианта (cyan/ink/slate) для 16-24px.
