# Owyx — дизайн-система

Живой документ для **сайта** (`owyxsite/`) и **лаунчера** (`apps/app` + `apps/app-frontend`).  
Сейчас продукт = **сайт + лаунчер** (по модели близко к Modrinth App + свой control-plane), без привязки к одному Minecraft-серверу и без плагина в текущем скоупе.

**Репо:** https://github.com/ebluffy/Owyx  
**Обновлено:** 2026-09-17

---

## 1. Продукт одной фразой

**Owyx** — свой Minecraft-лаунчер + сайт-аккаунт: скачал лаунчер, вошёл (Owyx или Microsoft), ставишь сборки и играешь. Сайт — регистрация, профиль, скины, новости, каталог для лаунчера. Игрок узнаёт бренд за секунду: тёмный космос + **циановый** акцент, без золота ванильного Minecraft-меню и без фиолетового AI-дефолта.

Не позиционируем продукт как «наш один сервер» и не тащим в UI/копирайт игровой IP / «основной сервер» на маркетинг-поверхностях.

## 2. Принципы (обязательны)

1. **Один бренд на сайте и в лаунчере** — одни токены, тон, CTA.
2. **Brand first** — на лендинге имя **Owyx** — hero-уровень, не мелкая надпись в навбаре.
3. **Одна композиция** первого экрана — не дашборд: бренд + одна мысль + один CTA + атмосфера.
4. **Тёмный мир, не серый шаблон** — глубина (градиенты, туман, лёгкий starfield / particles), не плоский `#111`.
5. **Циан = действие** — Play, primary CTA, фокус, статус «живо».
6. **Карточки sparingly** — только если без контейнера ломается смысл/клик; в hero карточек нет.
7. **Без UI-мусора** — не пилить hero статами, чипами, плавающими бейджами, тремя колонками промо, IP игрового сервера.
8. **RU по умолчанию**, EN — полный паритет строк, не смесь в одном экране.
9. **Доступность** — контраст текста к фону; фокус видимый; не полагаться только на цвет.
10. **Лаунчер + сайт first** — всё остальное (форум, шоп, будущий плагин) вне текущего визуального/продуктового фокуса или честный Coming Soon.

### Чего избегать (жёстко)

- Золото/янтарь Minecraft-дефолт (`#FFAA00`, `#FF6600`) как **primary**.
- Фиолетово-индиго «AI SaaS» градиенты на белом.
- Cream + terracotta + газетная вёрстка.
- Inter / Roboto / Arial как display.
- Glow-радиоактив, rounded-full пилюли статами, emoji как декор.
- Inset hero-картинки в скруглённых карточках вместо full-bleed атмосферы.
- Hero / home с «статус сервера + copy IP» / `play.owyx.site` как главный оффер.
- Копирайт «сайт ↔ лаунчер ↔ плагин» как текущий продукт (плагин — out of scope).

## 3. Токены (source of truth)

База — **лаунчер** (`apps/app-frontend` + shared UI tokens). Сайт подтягивается к ним.

| Токен | Значение | Роль |
|-------|----------|------|
| `--bg` | `#050508` | Глубокий фон |
| `--panel` | `#131319` | Панели / поверхности |
| `--panel-2` | `#14141c` | Вторичные панели |
| `--rail` | `#0e0e14` | Боковая навигация |
| `--line` | `#2a2b30` | Бордеры / разделители |
| `--text` | `#f3f4f6` | Основной текст |
| `--muted` | `#9aa0a8` | Вторичный текст |
| `--accent` | `#00e5ff` | **Primary** — CTA, ссылки, фокус, brand |
| `--accent-ink` | `#041018` | Текст на accent-кнопке |
| `--accent-violet` | `#8b5cf6` | Secondary highlight (rail active, редко) |
| `--ok` | `#5eead4` | Успех / онлайн |
| `--danger` | `#ff5c6c` | Ошибки / destructive |

**Радиусы:** 8–14px для контролов; модалки ~16–20px. Не «таблетки» на всё.  
**Тени:** мягкие, одна плоскость; без многослойного neon.  
**Progress / статус:** тонкая полоска accent по низу pill (как в лаунчере).

### Типографика

- **Display / brand:** `Unbounded` (заголовки) + **Onest** (UI/body) с кириллицей.
- **Body:** Onest ~15–16px, line-height ~1.5.
- **Mono:** Geist Mono — логи, версии, технические строки (не игровой IP в hero).

### Иконки и лого

- Логотип: hex / кристалл Owyx + слово **owyx** цветом `--accent`.
- Иконки: линейные, 1.5–2px stroke, цвет `text` / `muted`; active — accent.
- Аватары: круглые; Minecraft skin — ок в профиле / друзьях.

### Motion

- 2–3 осознанных движения: fade/slide hero, pulse статуса сервисов, hover CTA translateY(−1–2px).
- Без бесконечного glitter и тяжёлого параллакса.

## 4. Лаунчер (эталон UI)

**Стек:** Tauri 2 + Vue (`apps/app` / `apps/app-frontend`), fork Modrinth App shell без их бренда/Hosting.  
**Ощущение:** тёмный desktop shell, cyan Play, модалки настроек.

Сохранять:

- Rail слева (Home / Library / instances / + / settings; Owyx Servers — admin catalog).
- Аккаунты user-facing: только **Owyx** и **Microsoft** (без «offline nick» как отдельного пути).
- Filled pill inputs; settings = modal с табами.
- Progress: один global pill + optional tip скорость/размер.
- i18n ru/en полный паритет для наших строк.

Не тащить на сайт 1:1 chrome окна — только токены, тон, паттерны кнопок/полей.  
Не показывать Modrinth Hosting / Pride upsell / чужие support URL.

## 5. Сайт (`owyxsite/`) — целевой вид

**Цель:** визуально «брат» лаунчера: `#050508` + cyan CTA. Control-plane для аккаунта и каталога лаунчера — не лендинг одного MC-сервера.

### Информационная архитектура

| Зона | Маршруты | Задача |
|------|----------|--------|
| Маркетинг | `/` | Hero: бренд + ценность лаунчера + CTA скачать / войти. Опционально статус **сервисов сайта** (API/БД), не IP игры |
| Download | `/download` | Скачать лаунчер + 3 шага «скачал → вошёл → играешь» |
| Auth | `/login` `/register` `/verify` `/forgot-password` `/reset-password` | Чистые формы, RU/EN паритет плейсхолдеров |
| Кабинет | `/profile` | Аккаунт, скин, настройки |
| Админ | `/admin` | Каталог/новости/юзеры — тот же бренд |
| Парковка | `/forum` `/chat` `/online` `/shop` `/tokens` | Честный Coming Soon → CTA на **скачать лаунчер**, не на «сервер» |

Маршрут `/servers` не продаёт «основной сервер» — редирект на `/download` (или убрать из навигации).

### Hero (первый viewport)

Только:

1. Логотип / слово **Owyx** (hero-уровень).
2. Одна строка ценности про **лаунчер + аккаунт**.
3. Опционально компактный статус сервисов control-plane (API / БД / realtime).
4. Primary CTA **«Скачать лаунчер»** + secondary «Войти / Создать аккаунт».

> **Модель доступа — открытая.** Скачал → Owyx или Microsoft → Play. Без заявок модератору. Без привязки продукта к одному игровому серверу.

Фон: full-bleed атмосфера (градиент + particles). Не inset card-hero. Не золотой glow. Без паутины линий на canvas.

### Компоненты сайта

- **Header:** blur на `--bg`, ссылки muted → accent hover; brand слева. Ссылки только на живые зоны (download, auth, profile) — не раздувать нав community-заглушками.
- **Primary button:** тактильный cyan (градиент + лёгкая фаска / `:active`).
- **Secondary / ghost:** матовое стекло, тонкая граница.
- **Inputs:** filled dark (`--panel`), border `--line`, focus ring accent; плейсхолдеры из locale.
- **Footer:** минимальный.

### Тон копирайта

Коротко, по-человечески, RU. Про лаунчер и аккаунт. Не «экосистема плагин+сервер» как текущий оффер.

## 6. Связка (текущий скоуп)

```text
Сайт (аккаунт, профиль, скины, новости, каталог API)
        │
        └─► Лаунчер (Owyx login | Microsoft, сборки, Play, friends)
```

Один логотип, один accent, домены `owyx.site` / `api.owyx.site`. Скриншоты сайта и лаунчера рядом — один продукт.

Плагин / серверный runtime — **вне текущего дизайн-скоупа** (история в OwyxOld / отдельный трек). Не описывать в hero, header, download.
