# Owyx — единый дизайн-система

Живой документ для **сайта** (`owyxsite/`), **лаунчера** (`Launcher/`) и **плагина** (`owyxplugin/`).  
Цель: один бренд во всех поверхностях. Использовать как ТЗ для редизайна сайта и облачных агентов.

**Репо:** https://github.com/ebluffy/Owyx  
**Обновлено:** 2026-08-06

---

## 1. Продукт одной фразой

**Owyx** — экосистема приватного Minecraft: сайт (аккаунт, профиль, косметика) ↔ лаунчер (сборки, Play) ↔ плагин (логин/токен на сервере). Игрок узнаёт бренд за секунду: тёмный космос + **циановый** акцент, без «чужого» золота ванильного Minecraft-меню и без фиолетового AI-дефолта.

---

## 2. Принципы (обязательны)

1. **Один бренд на всех клиентах** — сайт, лаунчер, сообщения плагина в игре говорят одним языком цвета/тона.
2. **Brand first** — на лендинге имя **Owyx** — hero-уровень, не мелкая надпись в навбаре.
3. **Одна композиция** первого экрана — не дашборд: бренд + одна мысль + один CTA + атмосфера.
4. **Тёмный мир, не серый шаблон** — глубина (градиенты, туман, лёгкий starfield / particles), не плоский `#111`.
5. **Циан = действие** — Play, primary CTA, фокус, статус «живо».
6. **Карточки sparingly** — только если без контейнера ломается смысл/клик; в hero карточек нет.
7. **Без UI-мусора** — не пилить hero статами, чипами, плавающими бейджами, тремя колонками промо.
8. **RU по умолчанию**, EN — полный паритет строк, не смесь в одном экране.
9. **Доступность** — контраст текста к фону; фокус видимый; не полагаться только на цвет.
10. **Фаза 2 индивидуальности** — сейчас выравниваем токены; радикальный redesign layout ок, если токены и тон соблюдены.

### Чего избегать (жёстко)

- Золото/янтарь Minecraft-дефолт (`#FFAA00`, `#FF6600`) как **primary** на сайте (сейчас legacy — убрать при редизайне).
- Фиолетово-индиго «AI SaaS» градиенты на белом.
- Cream + terracotta + газетная вёрстка.
- Inter / Roboto / Arial как display (лаунчер уже кастомный стек; сайт — выразительный гротеск или уже согласованный web-font, не system UI по умолчанию для hero).
- Glow-радиоактив, rounded-full пилюли статами, emoji как декор.
- Inset hero-картинки в скруглённых карточках вместо full-bleed атмосферы.

## 3. Токены (source of truth)

База — **лаунчер** (`Launcher/apps/launcher/src/styles.css`). Сайт и плагин подтягиваются к ним.

| Токен | Значение | Роль |
|-------|----------|------|
| `--bg` | `#050508` | Глубокий фон |
| `--panel` | `#131319` | Панели / поверхности |
| `--panel-2` | `#14141c` | Вторичные панели |
| `--rail` | `#0e0e14` | Боковая навигация |
| `--line` | `#2a2b30` | Бордеры / разделители |
| `--text` | `#f3f4f6` | Основной текст |
| `--muted` | `#9aa0a8` | Вторичный текст |
| `--accent` | `#00e5ff` | **Primary** — CTA, ссылки, фокус, brand |
| `--accent-ink` | `#041018` | Текст на accent-кнопке |
| `--accent-violet` | `#8b5cf6` | Secondary highlight (rail active, редко) |
| `--ok` | `#5eead4` | Успех / онлайн |
| `--danger` | `#ff5c6c` | Ошибки / destructive |

**Радиусы:** 8–14px для контролов; модалки ~16–20px. Не «таблетки» на всё.  
**Тени:** мягкие, одна плоскость; без многослойного neon.  
**Progress / статус:** тонкая полоска accent по низу pill (как в лаунчере).

### Типографика

- **Display / brand:** `Unbounded` (заголовки) + **Onest** (UI/body) с кириллицей. Не Sora/Outfit/DM Sans fallback-каша; не Bricolage (нет Cyrillic на Google Fonts).
- **Body:** Onest ~15–16px, line-height ~1.5.
- **Mono:** Geist Mono / JetBrains-compatible — логи, IP, версии.

### Иконки и лого

- Логотип: hex / кристалл Owyx (как в лаунчере) + слово **owyx** цветом `--accent`.
- Иконки: линейные, 1.5–2px stroke, цвет `text` / `muted`; active — accent.
- Аватары: круглые; Minecraft skin — ок в контексте профиля/онлайна.

### Motion

- 2–3 осознанных движения на поверхность: fade/slide hero, pulse статуса online, hover CTA translateY(−1–2px).
- Без бесконечного glitter и параллакса, от которого тошнит.

## 4. Лаунчер (эталон UI уже в v0.1)

**Стек:** Tauri 2 + Vite HTML/CSS/TS.  
**Ощущение:** тёмный desktop shell, cyan Play, модалки настроек, status-pill в titlebar.

Сохранять:

- Rail слева (Home / Library / Servers roadmap / instances / + / settings).
- Filled pill inputs; settings = modal с табами.
- Progress: один global pill + optional tip скорость/размер.
- i18n ru/en полный паритет.

Не тащить на сайт 1:1 chrome окна (min/max/close) — только токены, тон, паттерны кнопок/полей.

## 5. Сайт (`owyxsite/`) — целевой вид

**Сейчас (legacy):** gold Minecraft (`#FFAA00`), glass + skin-фоны, Segoe UI — **не целевое**.  
**Цель редизайна:** визуально «брат» лаунчера: `#050508` + cyan CTA, тот же бренд Owyx.

### Информационная архитектура (сохранить маршруты, обновить оболочку)

| Зона | Маршруты (ориентир) | Задача экрана |
|------|---------------------|---------------|
| Маркетинг | `/` | Hero: бренд + сервер online/IP + CTA «Скачать лаунчер» (+ «Войти / Создать аккаунт») |
| Download | `/download` | Скачать лаунчер + 3 шага «скачал → вошёл → играешь» |
| Auth | `/login` `/register` `/verify` `/forgot-password` `/reset-password` | Чистые формы, без лишних карточек |
| Кабинет | `/profile` | Аккаунт, лаунчер (скачать/вход тем же аккаунтом), **внешний вид** (скин), настройки |
| Комьюнити | `/forum` `/chat` `/online` | Списки, топики, кто в сети |
| Экономика | `/shop` `/tokens` | Каталог (оплата — later) |
| Админ | `/admin` | Плотный инструмент, тот же бренд, не «другой продукт» |

### Hero (первый viewport)

Только:

1. Логотип / слово **Owyx** (hero-уровень, accent или почти-белый с accent-подчёркиванием).
2. Одна строка ценности (сервер / комьюнити) — muted.
3. Статус сервера + IP (копирование) — компактно.
4. Одна primary CTA **«Скачать лаунчер»** (accent fill) + secondary ghost «Войти / Создать аккаунт».

> **Модель доступа — открытая.** Игрок скачал лаунчер → ник → Play (offline), или вошёл аккаунтом Owyx. **Никаких «подай заявку и жди модератора».** Заявки убраны из продукта.

Фон: full-bleed атмосфера (тёмный градиент + лёгкий particles/starfield **или** приглушённые скины с сильным затемнением). Не inset card-hero. Не золотой glow.

### Компоненты сайта (паттерны)

- **Header:** прозрачный/blur на `--bg`, ссылки muted → accent hover; brand слева.
- **Primary button:** `--accent` / `--accent-ink`, radius ~10px.
- **Secondary:** ghost / outline `--line`.
- **Inputs:** filled dark (`--panel`), border `--line`, focus ring accent.
- **Footer:** минимальный, без стены ссылок.
- **Forum/chat:** denser UI допустим; те же токены.

### Тон копирайта

Коротко, по-человечески, RU. Без корпоративного «инновационной платформы». Плагин/лаунчер в текстах — как части одной экосистемы.

## 6. Плагин (`owyxplugin/`) — визуал в игре + бренд

Плагин почти без GUI; «дизайн» = **префиксы, сообщения, конфиг**.

- Префикс чата: `&bOwyx&7` / MiniMessage с hex `#00E5FF` (или legacy cyan), не золото Chiwawa.
- Команды: `/owyx` (+ алиасы со старого имени на переходный период).
- Kick/whitelist тексты: спокойные, с упоминанием сайта `owyx.site` / API `api.owyx.site`.
- Package / `plugin.yml` / JAR name — Owyx (см. корневой `PLAN.md`, раздел плагина).
- Не вводить отдельную «зелёную» или «золотую» палитру в сообщениях.

## 7. Связка экосистемы

```text
Сайт (аккаунт, косметика, токен)
    │
    ├─► Плагин (проверка токена / сессия на сервере)
    │
    └─► Лаунчер (offline | Owyx login | MS stub)
```

Один логотип, один accent, одни домены в копирайте. Скриншоты сайта и лаунчера рядом не должны выглядеть как два разных стартапа.

## 8. Чеклист приёмки редизайна сайта

- [ ] Primary accent = `#00e5ff` (не gold).
- [ ] Фон семейства `#050508` / панели `#131319`.
- [ ] Первый viewport: brand + 1 headline + 1 CTA + статус/IP; без стат-полок.
- [ ] Header/footer в том же языке, что лаунчер.
- [ ] Auth/profile/forum не «выпадают» в другой скин.
- [ ] RU/EN без смешанных экранов.
- [ ] Нет Inter-as-display / фиолетового SaaS-градиента / золотого btn-minecraft.
- [ ] Mobile: hero читаем, CTA не обрезан.

## 9. Для облачного агента (сайт)

При редизайне:

1. Прочитать этот файл целиком + корневой `PLAN.md` + текущий `frontend/app/**`.
2. Заменить токены в `globals.css` / Tailwind theme на таблицу §3.
3. Пересобрать `HeroSection`, Header, Footer, кнопки — без смены бизнес-логики API.
4. Сохранить маршруты и функции (auth, forum, chat, admin).
5. Не трогать секреты / `.env`; не выдумывать оплату.
6. Свериться с лаунчером `Launcher/apps/launcher/src/styles.css` при сомнении в цвете.

Phase 1 сайта = **визуальное выравнивание под лаунчер**. Новые фичи — только если не мешают редизайну.
