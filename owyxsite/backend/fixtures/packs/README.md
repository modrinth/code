# Demo pack fixture

Tiny zip used by the friends-sprint seed (`demo-vanilla`).

- File: `demo-vanilla.zip` (not a full Minecraft client — overlay only)
- SHA-256: see `demo-vanilla.sha256`
- Served by the backend at `/fixtures/packs/demo-vanilla.zip`

The launcher installs vanilla/loader first, then extracts this archive into
the instance `game/` folder.
